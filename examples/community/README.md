# Community Examples

Community-contributed Intentum examples. Each example demonstrates intent detection for a specific use case.

## Contributing

1. Fork the repository
2. Copy `template/` to `examples/community/<your-use-case>-intent/`
3. Implement your example following the template structure
4. Ensure it compiles and runs with `dotnet run`
5. Submit a pull request

## Requirements

- Must use Mock embedding provider (no API key required)
- Must include `README.md` with:
  - What the example does
  - How to run it
  - Expected output
- Must compile on .NET 10.0
- Must not depend on external services
- Follow naming convention: `<use-case>-intent`

## Template Structure

```
<your-use-case>-intent/
├── README.md
├── YourUseCase.csproj
└── Program.cs
```
