API Detayları & Entegrasyon Planı

1. Open-Meteo Climate API
Endpoint: https://climate-api.open-meteo.com/v1/climate
Veri: Sıcaklık, yağış, rüzgar, nem (1950-2050)
Modeller: CMIP6 HighResMIP (EC_Earth3P_HR, MPI_ESM1_2_XR, vb.)
Çözünürlük: ~10 km
API Key: Gerekmez ✓
GET /v1/climate?
  latitude=39.92&longitude=32.85
  &start_date=2030-01-01
  &end_date=2050-12-31
  &models=EC_Earth3P_HR
  &daily=temperature_2m_max,
    precipitation_sum
2. WRI Aqueduct Water Risk
Veri: Su stresi, sel riski, kuraklık, yeraltı suyu
Çözünürlük: Hidrolojik havza bazında
Senaryolar: Optimist / Pessimist (2030, 2050, 2080)
Erişim: CSV download + Google Earth Engine
Lisans: Creative Commons (attribution) ✓
Veri_seti: Aqueduct 4.0
  w_awr_def_tot_cat (toplam su riski)
  w_awr_bws_cat (su stresi)
  w_awr_bwd_cat (su kıtlığı)
  w_awr_giw_cat (yeraltı suyu)
  w_awr_cfr_cat (sel riski)
  → Country-level CSV import
3. Copernicus CDS (ERA5)
Endpoint: https://cds.climate.copernicus.eu
Veri: ERA5 yeniden analizi, deniz seviyesi, CO₂
Çözünürlük: 0.25° (~25 km)
Erişim: Ücretsiz kayıt gerekli
Kütüphane: cdsapi (Python) veya REST
Dataset: reanalysis-era5-single-levels
  Variables: sea_level, temperature,
    precipitation, wind_speed
  Time: hourly/daily aggregates
  Area: [90,-180,-90,180] global
  → Historical baseline hesaplama
4. Climate Monitor API
Endpoint: https://climatemonitor.info/api
Veri: CO₂, CH₄, N₂O, deniz seviyesi, buzul kütlesi
Format: JSON
API Key: Gerekmez ✓
Güncellik: Aylık seriler, güncel değerler
GET /api/v1/co2
  → CO₂ ppm trend (1958-günümüz)
GET /api/v1/sea-level
  → Deniz seviyesi mm trend
GET /api/v1/ice-mass
  → Grönland + Antarktika buzul
  → Trend çizgi grafikleri için
5. GADM GeoJSON — İdari Sınırlar
Kaynak: https://geodata.ucdavis.edu/gadm/gadm4.1/json/
Veri: Ülke > Bölge > İl > İlçe idari sınırları (Polygon geometri)
Format: GeoJSON FeatureCollection
Kapsam: 201 ülke, 4 seviye idari sınır
Kullanım: ECharts registerMap() ile haritaya register edilir
Örnek: Türkiye illeri
GET /gadm41_TUR.json
→ 81 il polygon geometrisi
→ Her il için risk renklendirmesi
→ Tıklama ile detay analizi
Fabrika Lokasyonu:
Kullanıcı lat/lng girer
→ En yakın ilçe tespit edilir
→ 10/25/50 km yarıçapı çizilir
→ Yarıçap içindeki polygon'lar
  analiz edilir (risk ortalaması)

Not: Tüm API'ler ücretsiz veya ücretsiz kayıt ile erişilebilir. WRI Aqueduct CSV download ücretsizdir, bulk API için Aqueduct Alliance üyeliği gerekebilir ama CSV import yeterlidir. Copernicus CDS ücretsiz kayıt ister.
