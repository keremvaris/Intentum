# Intentum.AI.SystemOne

Adapter for System One compatible decision engines (TypeSafe Jev wire protocol, `POST /v1/systemone`) used as Intentum `IIntentModel` implementations.

Supported engines: Kev, Laya, TinyJev, OpenDecision, Decision 1.0, Open-Jev, NanoJev, OpenJevPro, Foq — anything speaking the System One protocol.
